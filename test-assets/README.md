# Test Assets

Minimal sample files for each supported (and planned) file type.

## Text (supported)

| File | Type | Content |
|------|------|---------|
| `sample.txt` | Plain text | Meeting notes |
| `sample.md` | Markdown | Architecture decision record |
| `sample.html` | HTML | Company newsletter |
| `sample.csv` | CSV | Sales data |
| `sample.json` | JSON | Project config |
| `sample.xml` | XML | Book catalog |
| `sample.py` | Python | Health check server |
| `sample.log` | Log file | Server logs |

## Images (supported)

| File | Type | Content |
|------|------|---------|
| `sample.jpg` | JPEG | Mountain sunset scene |
| `sample.jpeg` | JPEG | Mountain sunset scene |
| `sample.png` | PNG | Mountain sunset scene |
| `sample.gif` | GIF | Mountain sunset scene |
| `sample.bmp` | BMP | Mountain sunset scene |
| `sample.tiff` | TIFF | Mountain sunset scene |
| `sample.tif` | TIFF | Mountain sunset scene |
| `sample.webp` | WebP | Mountain sunset scene |
| `sample.svg` | SVG | Mountain sunset scene (vector) |

## Documents (not yet supported)

| File | Type | Content |
|------|------|---------|
| `sample.docx` | Word | Budget proposal |
| `sample.pptx` | PowerPoint | Empty presentation |
| `sample.parquet` | Parquet | Minimal data file |
